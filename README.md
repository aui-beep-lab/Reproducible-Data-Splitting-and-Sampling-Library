This library provides reusable R functions for preparing data for machine learning workflows. It includes split_data for a standard train/test split, split_data_three_way for a train/validation/test split, stratified_split for preserving class balance when splitting datasets with a categorical target, and make_cv_folds for generating consistent cross-validation folds. All functions accept a configurable random seed so results are fully reproducible across runs and team members. The library reads a dataset directly from a CSV file, so it can be applied to any project by updating the file path. It relies only on base R with no additional package installation required. To use it, source the script, load your dataset with read.csv, and call any of the functions on your data frame.
